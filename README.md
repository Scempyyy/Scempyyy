## ⚡ Engineering Principles

- 🛡️ **Privacy by Architecture:** Software should respect user data autonomy. Prefer local-first computation, explainable scoring, and zero unnecessary cloud telemetry.
- ⚡ **Low Latency & High Signal:** Eliminate bloat. Use on-device models (e.g. Piper neural TTS, MediaPipe face mesh) for instantaneous response.
- 📦 **End-to-End Delivery:** Ideas mean little without execution. I build complete pipelines—from backend contracts and UI systems to signed production release binaries.
